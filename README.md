# EUI Pariah

Extra features for EllesmereUI on WoW Forever: DoT projection on nameplates, bag sort locks, nameplate Threat % placement, and a choice of reputation bar text.

## Install

Needs EllesmereUI. Copy the `EUI_Pariah` folder into `World of Warcraft/_forever_/Interface/AddOns/`. Settings are under **Pariah Tweaks** in EllesmereUI's options, or type `/pariah`.
